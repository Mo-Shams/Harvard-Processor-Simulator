# Test: triggers a FLUSH (branch taken)
# No stalls occur in this 3-stage pipeline — forwarding is implicit
# (EX writes register file before ID reads it, due to reverse execution order).
#
# Expected events:
#  - Cycle 7: BEQZ R1 1 executes, R1==0 → FLUSH, jump to instruction 6 (LDI R5 7)
#  - LDI R4 31 (instruction 5) is NEVER executed (flushed)
#
# Expected final registers:
#  R1 = 0   (LDI R1 0)
#  R2 = 5   (LDI R2 5)
#  R3 = 5   (LB loads 0, then ADD R3 R2 = 0+5 = 5)
#  R4 = 0   (LDI R4 31 was flushed — never ran)
#  R5 = 7   (LDI R5 7 is the branch target)
#
LDI R1 0      ; [0] R1 = 0  (used as branch condition)
LDI R2 5      ; [1] R2 = 5
LB R3 0       ; [2] R3 = DataMem[0] = 0
ADD R3 R2     ; [3] R3 = R3 + R2 = 0 + 5 = 5 (no stall — forwarding is implicit)
BEQZ R1 1     ; [4] FLUSH here: R1==0, target = 4+1+1 = 6
LDI R4 31     ; [5] FLUSHED - never executes
LDI R5 7      ; [6] branch target: R5 = 7
